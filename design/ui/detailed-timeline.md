# ⏰ Detailed Timeline & Action Sequence

## 📅 Complete Study Advancement Timeline

### 🎓 LECTURER TIMELINE

#### **Week 1-2: Account Setup & Profile**
```
Day 1-3:   Complete profile information
Day 4-7:   Upload educational background
Day 8-14:  Review dashboard, understand system
```

#### **Week 3-4: Study Calendar Creation**
```
Day 15-17: Create initial study calendar (DRAFT)
Day 18-21: Define study timeline and milestones
Day 22-28: Save draft, review requirements
```

#### **Week 5-8: Document Collection & Upload**
```
Week 5:    Upload Letter of Acceptance, Surat Pengantar Beasiswa
Week 6:    Upload Surat Izin Rektor, SK Dosen Tetap Yayasan
Week 7:    Upload Ijazah, Transkrip Nilai S1/S2
Week 8:    Upload SK Inpassing, SK JAD, Surat Pernyataan
           Submit each document for verification (DRAFT → PENDING)
```

#### **Week 9-10: Study Calendar Submission**
```
Day 57-63: Finalize study calendar
Day 64-70: Submit for approval (DRAFT → PENDING_APPROVAL)
```

#### **Week 11-14: Wait for Approvals**
```
Week 11-12: Monitor approval status
Week 13-14: Respond to any rejection comments
           Revise and resubmit if needed (REJECTED → PENDING_APPROVAL)
```

#### **Week 15-16: Study Commencement**
```
Day 99-105: Request to start study (APPROVED → ACTIVE)
Day 106-112: Begin actual study program
```

#### **Monthly (During Study): Semester Reports**
```
Month 1:   Upload semester reports (6 documents)
Month 2:   Submit for verification (DRAFT → PENDING)
Month 3:   Track verification status
Month 4:   Continue with next semester
```

#### **As Needed: Leave Management**
```
Day X:     Request official leave (ACTIVE → LEAVE)
Day Y:     Return from leave (LEAVE → ACTIVE)
```

#### **Final Semester: Completion**
```
Month N-1: Upload final documents (4 documents)
Month N:   Submit for verification (DRAFT → PENDING)
Month N+1: Request study completion (ACTIVE → FINISHED)
```

## 🔄 Critical Path Analysis

### 📋 Critical Path 1: Document Verification
```
Lecturer Upload → Staff Verify → Head HR Oversee
Timeline: 4 weeks
Dependencies: All documents must be verified before calendar submission
```

### 📋 Critical Path 2: Study Calendar Approval
```
Lecturer Submit → Head Prodi/Vice Dean Approve
Timeline: 2-4 weeks
Dependencies: All documents verified, calendar complete
```

### 📋 Critical Path 3: Approval Document Process
```
Staff Upload → Head Prodi Approve L1 → Head KK Approve L2
Timeline: 2-3 weeks
Dependencies: Calendar approved, documents ready
```

### 📋 Critical Path 4: Study Start
```
Lecturer Request → Head Prodi/Vice Dean Approve → Study Active
Timeline: 1 week
Dependencies: All approvals complete, documents verified
```

### 📋 Critical Path 5: Study Completion
```
Lecturer Submit Final Reports → Staff Verify → Head Prodi Approve Completion
Timeline: 4-6 weeks
Dependencies: All final reports verified, study requirements met
```

## 🎯 Milestone Tracking

### 📋 Milestone 1: Profile Complete (Week 2)
- **Success Criteria**: All profile fields completed
- **Owner**: Lecturer
- **Dependencies**: None

### 📋 Milestone 2: Documents Uploaded (Week 8)
- **Success Criteria**: All required documents uploaded and submitted
- **Owner**: Lecturer
- **Dependencies**: Profile complete

### 📋 Milestone 3: Documents Verified (Week 10)
- **Success Criteria**: All documents reach VERIFIED state
- **Owner**: Staff
- **Dependencies**: Documents uploaded

### 📋 Milestone 4: Calendar Approved (Week 14)
- **Success Criteria**: Study calendar reaches APPROVED state
- **Owner**: Head of Study Program/Vice Dean
- **Dependencies**: Documents verified

### 📋 Milestone 5: Approval Documents Complete (Week 17)
- **Success Criteria**: Approval documents reach APPROVED state
- **Owner**: Head of Research Group
- **Dependencies**: Calendar approved

### 📋 Milestone 6: Study Active (Week 18)
- **Success Criteria**: Study calendar reaches ACTIVE state
- **Owner**: Lecturer
- **Dependencies**: All approvals complete

### 📋 Milestone 7: Study Complete (Month N+1)
- **Success Criteria**: Study calendar reaches FINISHED state
- **Owner**: Lecturer
- **Dependencies**: All final reports verified
